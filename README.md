## 🚀 The next generation of TunnlTo is here: Meet [Rouler](https://rouler.io/?utm_source=github&utm_medium=referral).

I built Rouler based on all the feedback and feature requests from the TunnlTo community. TunnlTo's legacy architecture had reached its limits. Instead of being locked into a single protocol and relying on third-party components, Rouler uses a custom-built, lightweight network engine. This unlocks performance and features that TunnlTo simply cannot support:

- **Use Your Native VPN Clients:** TunnlTo limits you to WireGuard, requiring you to manually download and import config files from providers like NordVPN. Rouler works directly with your existing VPN apps. This means you can easily use corporate VPNs that require complex authentication alongside WireGuard, Tailscale, and OpenVPN, without any config file hassle.

- **Advanced Multi-Routing:** Send Firefox to Tailscale, Chrome to WireGuard, and let your games bypass the VPN entirely, all at the same time.

- **Live Transparency:** TunnlTo was limited to a basic, raw text log dumped from a third-party driver. Rouler shows you exactly what routing decisions it is making and *why*. You get an easy-to-digest, real-time view of your traffic broken down against each app and custom rule, removing all the guesswork.

- **Purpose-Built Driver:** TunnlTo's biggest limitation was trying to force a UI around a third-party driver. I wrote Rouler's network driver myself from the ground up. Because it was designed specifically for split-tunneling rather than bolted on as an afterthought, it operates much faster, is highly stable, and is fully optimized for the exact features TunnlTo couldn't deliver.
